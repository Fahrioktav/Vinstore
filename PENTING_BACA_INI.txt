PENTING - UNTUK MENJALANKAN WEBSITE:
===============================================

SETIAP KALI mau jalankan Laravel, Anda HARUS:
1. Buka terminal/command prompt BARU
2. Jalankan command ini DULU sebelum php artisan serve:

   Remove-Item Env:\DB_*

3. Baru jalankan:

   php artisan serve

===============================================
ATAU, lebih mudah, gunakan file ini:
===============================================

Saya sudah buatkan file: run_server.bat
Tinggal double-click file itu untuk start server!

===============================================
KENAPA HARUS BEGINI?
===============================================

Laragon set Environment Variable di Windows yang
override file .env Anda. Jadi setiap kali buka
terminal baru, environment variable lama (dengan
username root dan password kosong) akan ter-load lagi.

Command "Remove-Item Env:\DB_*" menghapus environment
variable itu agar Laravel membaca dari file .env.

===============================================
SOLUSI PERMANEN (Optional):
===============================================

Jika mau fix permanen, restart Laragon atau restart
komputer. Tapi cara di atas (hapus env variable dulu)
sudah cukup untuk development.

===============================================
UNTUK DEPLOYMENT KE SERVER:
===============================================

Di server production, TIDAK PERLU worry tentang
environment variable Laragon. Cukup pastikan:

1. Update .env di server dengan:
   APP_URL=https://yourdomain.com
   DB_PASSWORD=<password database server>

2. Update Google Cloud Console dengan redirect URI:
   https://yourdomain.com/auth/google/callback
